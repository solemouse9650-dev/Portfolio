# Zentro Web

Portfolio profesional de diseño y desarrollo web construido con React y Vite.

## Desarrollo local

```bash
npm install
npm run dev
```

Abrí la URL que muestra Vite en la terminal. No abras `index.html` directamente: es la entrada de una aplicación React.

## Producción

```bash
npm run build
npm run preview
```

El workflow de GitHub Actions publica automáticamente `dist` en GitHub Pages al enviar cambios a `main`.
